📚 درباره برنامه

مدیریت تکالیف مدرسه، یه برنامه ساده و کامل برای مدیریت کارهای دانش‌آموزی هست.

  • نسخه: ۳.۵
  • فناوری: HTML + CSS + JavaScript + Supabase
  • ذخیره‌سازی: localStorage + ابر (Supabase)

🔐 حساب کاربری

با ساخت حساب کاربری، داده‌ها توی ابر ذخیره می‌شن و از هر دستگاهی قابل دسترسن. همچنین می‌تونی بات بله رو وصل کنی.

📖 راهنمای استفاده

چطور کار اضافه کنم؟

روی دکمه شناور ➕ پایین صفحه کلیک کن. فرم رو پر کن و ذخیره بزن.

چطور برنامه هفتگی رو تنظیم کنم؟

به تب «برنامه → برنامه هفتگی» برو. اسم درس هر زنگ رو وارد کن. ساعت شروع و پایان هر زنگ رو هم می‌تونی وارد کنی.

چطور از تقویم استفاده کنم؟

به تب «برنامه → تقویم» برو. روزها با رنگ‌بندی وضعیت کارها نمایش داده می‌شن. روی هر روز کلیک کن تا کارهای اون روز رو ببینی.

چطور آمار بگیرم؟

به تب «کار و دروس → آمار» برو. آمار کلی، بر اساس درس، اولویت، نوع، روز هفته و بازه‌ای نمایش داده می‌شه.

چطور یادداشت اضافه کنم؟

توی صفحه هر درس، تب یادداشت‌ها → دکمه «➕ یادداشت جدید». یا توی «بیشتر → یادداشت شخصی».

چطور بکاپ بگیرم و برگردونم؟

از هدر یا تنظیمات، دکمه «بکاپ JSON» رو بزن تا فایل بکاپ دانلود بشه. برای بازیابی، «بازیابی JSON» رو بزن و فایل رو انتخاب کن.

چطور حساب کاربری بسازم؟

روی دکمه «🔐 ورود» توی هدر کلیک کن. تب «ثبت‌نام» رو بزن. اسم، نام کاربری (انگلیسی) و پسورد رو وارد کن.

چطور بات بله رو وصل کنم؟

بعد از لاگین، توی «درباره → اتصال به بات بله» کد ۶ رقمی بگیر. توی بات بله بزن: 784512 یا /link 784512.

چطور تم رو عوض کنم؟

از هدر (دکمه سریع) یا از تنظیمات (همه تم‌ها) می‌تونی تم رو عوض کنی.

🎓 راهنمای پیشرفته

حضوری و آفلاین چیه؟

حضوری: کارهایی که روز و ساعت تحویل مشخصی دارن و به برنامه هفتگی وصل می‌شن. توی خونه تحویلشون با 📌 مشخص می‌شن.

آفلاین: کارهایی که ساعت آزاد دارن و فقط درسشون به برنامه هفتگی وصله.

کارها توی برنامه هفتگی چطور نمایش داده می‌شن؟

هر کار توی همه زنگ‌های درسش (قبل از موعد و خود موعد) نمایش داده می‌شه. بعد از موعد، اگه انجام نشده باشه با برچسب «عقب‌افتاده» و اگه انجام شده باشه، حذف می‌شه.

زیرکارها چطور کار می‌کنن؟

هر کار می‌تونه چند زیرکار داشته باشه. توی کارت کار، ۳ تای اول نمایش داده می‌شن. برای دیدن همه، روی عنوان کار کلیک کن و توی پنل جزئیات همه رو ببین و مدیریت کن.

رنگ‌بندی تقویم چطوره؟

🟢 سبز: همه کارها انجام شده

🟠 نارنجی: کار انجام‌نشده (هنوز موعد نرسیده)

🔴 قرمز: کار عقب‌افتاده داره

تفاوت حالت مهمان و لاگین چیه؟

مهمان: داده‌ها فقط روی دستگاه خودت (localStorage). اگه مرورگر پاک بشه، داده‌ها می‌رن.

لاگین: داده‌ها روی ابر (Supabase) + دستگاه. از هر دستگاهی قابل دسترس. امکان اتصال بات.

❓ سوالات متداول

داده‌هام کجا ذخیره می‌شه؟

توی حالت مهمان: فقط localStorage. توی حالت لاگین: localStorage + Supabase.

چرا برنامه هفتگی خالیه؟

چون هنوز اسم درسی وارد نکردی. به تب «برنامه → برنامه هفتگی» برو و برای هر زنگ، اسم درس را وارد کن.

چطور درس جدید اضافه کنم؟

کافیه توی برنامه هفتگی، یه خونه رو پر کنی با اسم درس جدید. بعد توی فرم افزودن کار، اون درس توی منوی کشویی ظاهر می‌شه.

بات بله چیه؟ چطور کار می‌کنه؟

یه بات توی پیام‌رسان بله که به همون اکانت وب اپت وصل می‌شه. از اونجا هم می‌تونی کار اضافه کنی و هم داده‌ها رو ببینی.

چرا بعد از لاگین، داده‌هام نمایش داده نمی‌شن؟

اگه توی حالت مهمان داده داشتی، بعد از لاگین ازت پرسیده می‌شه که منتقل بشن یا نه. اگه منتقل شدن، چند ثانیه صبر کن تا sync بشن.
