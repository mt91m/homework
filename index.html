درباره برنامه

مدیریت تکالیف مدرسه، یه برنامه ساده و کامل برای مدیریت کارهای دانش‌آموزی.

  • نسخه: ۳
  • فناوری: HTML + CSS + JavaScript خالص
  • ذخیره‌سازی: localStorage

🔐 حساب کاربری

با ساخت حساب کاربری، داده‌ها توی ابر ذخیره می‌شن و از هر دستگاهی قابل دسترسن.

  • بدون حساب: داده‌ها فقط روی همین دستگاه
  • با حساب: داده‌ها روی ابر + دستگاه
  • برای اتصال بات بله: از تنظیمات کد بگیر

برنامه روزانه چیه؟

برای هر روز، برنامه‌های خودت رو مثل کاغذ یادداشت می‌نویسی. با دکمه‌های روز قبل و بعد می‌تونی جابه‌جا بشی.

دفترچه یادداشت درسی کجاست؟
